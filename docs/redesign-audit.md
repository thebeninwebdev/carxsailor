# Product audit and revised journey

The repository uses the root `app/` directory, Next.js 16.3.2, React 19, TypeScript, Tailwind 4, Better Auth with the MongoDB adapter, and Mongoose models. There is no src/app or existing middleware. The server layout retrieves the session; login and registration use the Better Auth client and refresh the router. Buyer, seller and admin layouts enforce access. Seller approvals and listings remain separate from the buyer journey.

Before: the homepage had three sections and advertised a conversational adviser. Visitors could submit free text anonymously. An optional AI provider parses preferences, with a deterministic local parser as fallback. Budget, transmission, engine health, mileage, seats, years and body type filter listings; seven weighted ratings rank eligible cars, with small preferred-make and verified-inspection bonuses. Only the top three recommendations are shown. The score is a ranking index, not a likelihood of satisfaction. Missing ratings were silently ignored, and explanations could label weak ratings as strong merely because their weighted contribution was large.

The guided-mode anchor had no destination. There was no compare route. Favorites POST/DELETE existed, but the button started unsaved on every render, swallowed failures, and the saved-cars page was a placeholder. AdviserSession existed but history and saving were not connected. Login preserved simple next URLs, but nested protected routes were reduced to their layout destination. The mobile menu disappeared between 768 and 900 pixels while desktop navigation was also hidden. Listing images bypassed optimization. Stock seed photos cannot be assumed to accurately identify vehicles.

Revised architecture: Discover (/cars), Decision Support (/car-adviser), Compare (/compare), My Garage (/dashboard), Saved cars (/dashboard/favorites), My decisions (/dashboard/recommendations). Public browsing, guidance, ranking and comparison stay anonymous. Only saving and seller inquiries require sign-in. Guided answers and results survive the sign-in round trip in session storage; saved decisions are recomputed on the server and stored using the existing AdviserSession model. No invented testimonials, usage statistics, ground-clearance evaluation, resale assessment or measured fuel-consumption claims.

Journey: homepage → guided introduction → budget → vehicle requirements → priorities → review → explained results → compare → save → sign in if needed → same context → My Garage. Existing free-text advice remains available. Database counts and available manufacturers support homepage stats. No new schema or migration is required.
